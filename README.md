The Iris dataset contains 150 samples equally distributed across three flower species: Setosa, Versicolor, and Virginica. Exploratory Data Analysis showed that Petal Length and Petal Width are the most discriminative features, while sepal measurements exhibit more overlap. Four classification algorithms—Logistic Regression, K-Nearest Neighbors (KNN), Decision Tree, and Random Forest—were trained and evaluated using an 80/20 train-test split. Model performance was assessed using accuracy, confusion matrix, and classification report. Random Forest and KNN achieved the highest accuracy on the test set, making them the best-performing models for this dataset. Overall, the project demonstrates that machine learning models can accurately classify iris flower species using simple physical measurements.
